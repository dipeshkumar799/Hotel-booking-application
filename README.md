# OUR_ROLEX  🏡

A full-stack Airbnb-inspired web application built using Node.js, Express.js, MongoDB, and EJS.

## 🌐 Live Demo

[Visit My Website] https://hotel-booking-application-1.onrender.com

## ✨ Features

- User authentication (Signup and Login)
- Create, edit, and delete listings
- Upload listing images
- Add reviews to listings
- Session management
- Responsive user interface

## 🛠️ Technologies Used

- HTML, CSS, Bootstrap
- JavaScript
- Node.js
- Express.js
- MongoDB and Mongoose
- EJS
- Passport.js
- Cloudinary

## ⚙️ Run Locally

1. Clone this repository:

   `git clone https://github.com/dipeshkumar799/Hotel-booking-application`

2. Open the project folder:

   `cd airbnb`

3. Install dependencies:

   `npm install`

4. Create a `.env` file with the environment variables required by the application.

5. Start the server:

   `node app.js`

6. Open `http://localhost:3000` in your browser.

## 🔒 Security

Never upload your `.env` file or expose passwords, database credentials, or API secrets.
